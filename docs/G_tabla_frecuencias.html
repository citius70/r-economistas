G. Tabla de frecuencias

1. Frecuencias Unidimensionales table y prop.table

1.1. Frecuencias absoluta con table()

La función table() simplemente cuenta cuántas veces aparece cada valor en tu conjunto (por ejemplo, una columna de una data) de datos. Es el conteo directo.

Si usamos la columna cyl (cilindros) de los coches en mtcars:

# Creamos la tabla de conteo 
fa <- table(mtcars$cyl)  

# Ver el resultado 
print(fa)
## 
##  4  6  8 
## 11  7 14

¿Qué verás? R te dirá algo como:

  • 4: 11 (Hay 11 coches de 4 cilindros)

  • 6: 7 (Hay 7 coches de 6 cilindros)

  • 8: 14 (Hay 14 coches de 8 cilindros)

1.2. Frecuencia Relativa con prop.table()

A veces no quieres saber cuántos hay, sino qué porcentaje del total representan. Para eso usamos prop.table().

Ojo aquí: Muy importante: prop.table() no se aplica directamente a los datos iniciales, sino a una tabla que ya hayas creado con table(), en ente caso sobre la tabla fa.

# Convertimos la tabla anterior en proporciones (del 0 al 1)
proporciones <- prop.table(fa)

print(proporciones)
## 
##       4       6       8 
## 0.34375 0.21875 0.43750

Se interpreta: el 34.38% de los coches tienen 4 cilindros, el 21.88% tiene 6 cilindros y el 43.75% tienen 8 cilindros.

2. Tablas Bidimensionales (Tablas de Contingencia)

Ideales para analizar la relación entre dos variables categóricas. Las tablas de contingencia nos permiten ver si existe una “amistad” entre dos variables.

Por ejemplo: ¿Los coches con más cilindros suelen ser automáticos o manuales?

2.1. La tabla básica table(var1, var2)

Para cruzar datos en R, simplemente pasas dos columnas a la función table(). Usemos cyl (cilindros) y am (transmisión: 0 = automático, 1 = manual):

# Creamos la tabla bidimensional con dos columnas cyl y am
tabla_bidimen <- table(mtcars$cyl, mtcars$am)

print(tabla_bidimen)
##    
##      0  1
##   4  3  8
##   6  4  3
##   8 12  2

Interpretación: Hay 3 coches de 4 cilindros automáticos (0)

3. Construcción de una Tabla de Frecuencias Completa

Para variables cualitativas (numéricas), podemos ensamblar una tabla profesional que incluya frecuencias absolutas (\(n_i\)), acumuladas (\(N_i\)), relativas (\(f_i\)) y relativas acumuladas (\(F_i\)).

Un pequeño detalle técnico:

El comando [, -4] que usaste es muy inteligente. Cuando haces data.frame(fa, fr...), R repite la columna de las categorías porque tanto fa como fr la llevan consigo. Al poner -4, borras esa columna repetida para que la tabla quede impecable.

4. Agrupación en Intervalos (Variables Numéricas)

Para variables continuas, es necesario convertir valores numéricos en intervalos categóricos mediante cut().

Ejemplo básico

Qué hace cada parte

1️⃣ temp → vector de temperaturas.
2️⃣ cut(temp, breaks = c(0, 20, 30, 50)) → divide los valores en intervalos:

  • (0,20] → valores mayores que 0 hasta 20

  • (20,30] → valores mayores que 20 hasta 30

  • (30,50] → valores mayores que 30 hasta 50

  • Nota: por defecto cut() el intervalo incluye el límite superior (a,b].

3️⃣ temp_intervalos → factor con el intervalo asignado a cada temperatura.

temp <- c(22.52, 18.70, 19.61, 22.79, 29.38, 30.19, 33.16, 36.97, 33.29, 28.98, 24.31, 22.43)

# Agrupación en rangos definidos
temp_intervalos <- cut(temp, breaks = c(0, 20, 30, 50))

# Mostramos los intervalos hechos
temp_intervalos
##  [1] (20,30] (0,20]  (0,20]  (20,30] (20,30] (30,50] (30,50] (30,50] (30,50]
## [10] (20,30] (20,30] (20,30]
## Levels: (0,20] (20,30] (30,50]

Aplicación práctica en Pediatría

Podemos usar aggregate() para resumir datos numéricos según los intervalos de edad creados.

  • Lectura de datos
    Se carga el conjunto de datos children.csv, que contiene la columna edad y varias variables numéricas (peso, altura, talla, etc.).

  • Agrupación por intervalos
    Se crean intervalos de edad de 1 año (por ejemplo, de 5 a 19 años) utilizando la función cut(). Cada niño queda asignado al intervalo correspondiente según su edad.

  • Cálculo de medias
    Se calcula la media de cada variable numérica para cada intervalo de edad con aggregate(), ignorando valores faltantes. Esto genera un resumen donde cada fila representa un intervalo y cada columna la media de una variable.

  • Frecuencia de intervalos (opcional)
    Se puede comprobar cuántos niños hay en cada intervalo para interpretar correctamente las medias.

pediatria <- read.csv2("children.csv")

# Creamos intervalos de edad de 1 en 1 año (de 5 a 19)
edad_intervalos <- cut(pediatria$edad, breaks = seq(5, 19))

# Calculamos la media de todas las variables numéricas por cada grupo de edad
resumen_edad <- aggregate(pediatria[, -1], by = list(edad = edad_intervalos), 
                          FUN = mean, na.rm = TRUE)
